Java full-stack — most at home in the API layer

I'm a Java Full Stack Developer based in Ahmedabad, Gujarat, working at Accenture as a Custom Software Sr. Analyst. Most of my day is Java and Spring — designing REST API endpoints and the services behind them, then wiring them into an Angular front end.

On the Vodafone Germany platform I've done a lot of Kafka and Spring REST work: migrating legacy stream apps into Spring Cloud Data Flow and building REST services that trigger Spark jobs and expose their results. A year onsite in Germany taught me how much a clean, well-documented endpoint matters when a whole team depends on it.

Earlier, at Infosys, I built a Spring REST + Spring Data JPA backend for BP that pulled live data from ServiceNow and Azure DevOps into a responsive Angular dashboard. Going forward, this is the work I most want to do more of — designing robust API endpoints and the backend that powers them.
